About

Map2Vector とは？
「編集できる地図」を、その場で。

Map2Vector は、OpenStreetMap（オープンな地図データ）をもとに、Illustratorでそのまま編集できる、レイヤー分けされた模式地図のSVGを作る無料のブラウザツールです。案内図・アクセスマップ・チラシ・ポスターなどのデザイン制作の下地として使えます。

何が便利なのか

お店やイベントの「案内図」をデザインするとき、これまでは地図サービスのスクリーンショットをなぞって手作業でトレースしたり、一から手描きしたりと、とても手間がかかりました。しかも地図サービスの画面をそのまま印刷物に使うのは、利用規約や著作権の面で問題になりがちです。

Map2Vector は、範囲を選んでボタンを押すだけで、道路・建物・緑地・川・鉄道・施設アイコンなどを種類ごとにレイヤー分けしたSVGを書き出します。SVGなので、Illustrator や Inkscape で開いて色・線幅・文字・不要な要素の削除まで自由に編集できます。「トレースの手間ゼロで、デザインの出発点が手に入る」——これが一番の価値です。

こんな人に向いています

  • グラフィックデザイナー / 印刷・DTP：案内図やアクセスマップを、イラレ素材として素早く用意したい
  • 店舗・サロン・クリニック：ショップカードやチラシに載せる、デザインされた地図がほしい
  • イベント・マルシェ主催者：ポスターやフライヤーに載せるアクセスマップを作りたい
  • 不動産・観光・自治体：物件周辺図や散策マップの下地に
  • Web制作者：サイトの「アクセス」ページ用に、軽くて綺麗なベクター地図がほしい

主な特徴

  • レイヤー分けSVG：道路・建物・緑地・水域・鉄道・注記・施設アイコンなどを分けて出力。必要な層だけ触れます。
  • 直角デフォルメ（模式図）モード：主要な道路を垂直・水平に整えた、案内図らしいスッキリした表現に。
  • 施設アイコン：コンビニ・ガソリンスタンド・病院・薬局・銀行・飲食店・バス停・電停などをイラスト化。
  • 日本語 / 英語ラベル対応：地名や施設名を日英で切り替え。海外向け制作にも。
  • Illustratorでそのまま編集：出力はSVG。色や文字を自由に作り込めます。

データについて

地図データは © OpenStreetMap contributors（ODbL ライセンス）を利用しています。出力物を公開・配布する際は、クレジット表記（© OpenStreetMap contributors）を残してください。詳しくは利用規約・免責をご覧ください。

※ Map2Vector が生成する地図は、見やすさを優先して簡略化・変形された「模式図」です。正確な地図ではないため、測量・ナビ・法的用途には使えません。デザインの下書きとしてご利用ください。

English

What is Map2Vector?

Map2Vector is a free browser tool that turns OpenStreetMap data into a layered, Illustrator-editable SVG of a simplified schematic map. It is made for design work — access maps, flyers, posters and similar printed or web materials.

Why it helps

Designing an access map usually means tracing a screenshot by hand or drawing from scratch, and using a map service's screenshot directly in print often raises licensing problems. Map2Vector instead exports roads, buildings, green areas, water, railways and facility icons as separate layers, so you can open the SVG in Illustrator or Inkscape and freely restyle colors, strokes, labels, and remove anything you don't need. No tracing — you start from a clean vector base.

Who it's for

Graphic / print designers, shops and clinics, event organizers, real-estate and tourism, and web makers who need a light, clean vector map for an "Access" page.

Key features

Layered SVG output, a right-angle schematic ("deformed map") mode, illustrated facility icons, Japanese / English labels, and direct editing in Illustrator.

Data

Map data is © OpenStreetMap contributors (ODbL). Keep the attribution in anything you publish. The output is a simplified schematic — not an accurate map — so it must not be used for surveying, navigation or legal purposes. See the Terms & Disclaimer.
